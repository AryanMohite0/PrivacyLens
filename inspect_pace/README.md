# Pace — Shopping Rewards

A standalone Manifest V3 Chrome extension frontend. The offers, points and member counts are sample data. Activation does not track purchases or award real cashback. No accounts or external services are connected.

## Install
1. Unzip `pace-chrome-extension.zip`.
2. Open `chrome://extensions` in Chrome (or the extensions page in Edge/Brave).
3. Enable **Developer mode**.
4. Click **Load unpacked** and select this folder (the one containing manifest.json).
5. Pin Pace in the browser toolbar and click its icon.

Follow brands, save offers, activate demo offers and change preferences. State is saved in chrome.storage.local. No background worker, host permissions, remote scripts or browsing-history access is used. Reminder settings are a preference only, not a notification service.

The included headphones is a generated concept image, not an actual Sony product. Sony, Amazon and Zara names are used as demo brand examples; this project is not affiliated with them.
